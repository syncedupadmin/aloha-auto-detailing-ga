# Aloha Auto Detailing demo

Source-grounded demonstration site for Aloha Auto Detailing in Peachtree City, Georgia.

## Content sources

- Current booking and service experience: `https://leads.alohamobiledetailing.com/`
- Live booking provider preserved: Urable virtual shop linked by the current site.
- Phone, email, address and service-area facts: current Aloha pages and public profile at the supplied address.
- Photography: real photographs already published by Aloha through its current LeadConnector/CDN site. No generated imagery is used.

## Demo policy

This build sends `X-Robots-Tag: noindex, nofollow, noarchive` and returns a disallow-all `robots.txt` until a production-domain launch is authorized.
